44. HOW CLAUDE CODE SHOULD WORK

At the beginning of EVERY sprint:

Read this context.md.

Read the sprint-specific instructions.

Inspect the current repository.

Inspect existing implementation before changing it.

Identify what is already complete.

Do not rebuild working systems unnecessarily.

Explain the implementation plan briefly.

Implement only the current sprint.

Test the implementation.

Run type checking/linting/build where applicable.

Summarise what changed.

List anything that requires visual review.

Stop.

Do not automatically continue into the next sprint.
